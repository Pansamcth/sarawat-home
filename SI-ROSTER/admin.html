ระบบเสียงไฮบริดและการทดสอบ (Hybrid Sound System)

สถาปัตยกรรมระบบเสียง 2 ชั้น (Dual-Engine Fallback) MP3 Backup Ready

ระบบจะใช้ Web Audio Synthesizer เป็นหลัก และมี ไฟล์เสียง MP3 ในระบบเว็บสำรอง ในกรณีที่เบราว์เซอร์หรือมือถือบล็อค API หรือเกิดข้อผิดพลาด

1. สัมผัสปุ่ม (Soft Tap) Global Tap

เสียงตอบรับสัมผัสสไตล์ iOS Haptic Tap ทำงานอัตโนมัติเมื่อผู้ใช้แตะปุ่มหรือการ์ด

2. ลงหน้าที่สำเร็จ (Success) Velvety Chime

เสียงกระดิ่งแก้ว Marimba คอร์ดเมเจอร์นุ่มนวลเป็นพิเศษ พร้อม Low-pass filter เมื่อลงหน้าที่สำเร็จ

3. กิจกรรมใหม่ (New Activity) Realtime Feed

เสียงแจ้งเตือนคู่เสียงใส (A5 -> E6) แจ้งเตือนเมื่อระบบตรวจพบว่ามีกิจกรรมใหม่

4. ข้อผิดพลาด (Warning) Soft Warning

เสียงเตือนโทนต่ำนุ่มนวล (Eb4 -> C4) สุภาพ ไม่กระโชกโฮกฮาก เมื่อเกิดข้อผิดพลาด

5. แอดมินบันทึกข้อมูล (Admin) Admin Action

เสียงคอร์ด 3 โน้ตยืนยันความสำเร็จ (F5 -> A5 -> C6) เมื่อแอดมินสร้างหรือแก้ไขกิจกรรมหลังบ้าน
