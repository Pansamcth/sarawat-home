จัดการบัญชีผู้ดูแลระบบ (Admin Users Management) 👑 Super Admin
คุณสามารถสร้างแอดมินใหม่ กำหนดสิทธิ์เป็น Admin ธรรมดา หรือ Super Admin และจัดการผู้ดูแลทั้งหมดได้ที่หน้าจัดการผู้ดูแลระบบ

สำรองและนำเข้าข้อมูล (Data Backup & Synchronization)

เนื่องจากเว็บดีพลอยบน Vercel แบบ Static Web ข้อมูลจะถูกบันทึกในเบราว์เซอร์ คุณสามารถสำรองข้อมูลเป็นไฟล์ JSON เพื่อนำไปเปิดในเครื่องอื่น หรือเก็บไว้เป็นชุดข้อมูลสำรองได้ตลอดเวลา

ส่งออกข้อมูลสำรอง (Export JSON)

ดาวน์โหลดข้อมูลข่าวสาร กิจกรรม ตารางงาน และการตั้งค่าทั้งหมดลงในไฟล์ sarawat_data_backup.json

นำเข้าข้อมูลสำรอง (Import JSON)

เลือกไฟล์ JSON ที่เคยสำรองไว้เพื่อกู้คืนข้อมูลหรืออัปเดตข้อมูลชุดใหม่

รีเซ็ตเป็นค่าเริ่มต้นจากโรงเรียน

หากต้องการล้างข้อมูลที่แก้ไขทั้งหมด และโหลดข้อมูลมาตรฐานตั้งต้นของสารวัตรนักเรียนปี 2569 กลับมา

เพิ่มบัญชีผู้ดูแลระบบใหม่

สรุปสิทธิ์ของแต่ละยศผู้ดูแล

👑 Super Admin (ผู้ดูแลระบบสูงสุด)
  • กำหนดค่าและปรับเปลี่ยนระบบฐานข้อมูล ได้อย่างอิสระ
  • เข้าถึงหน้านี้ เพื่อสร้าง/รีเซ็ตรหัส/ลบบัญชีผู้ดูแลระบบทั้งหมดได้
  • แก้ไขและจัดการข่าวสาร กิจกรรม ตารางงาน และการสำรองข้อมูลได้ครบทุกฟังก์ชัน
🛡️ Admin ธรรมดา (ผู้ดูแลทั่วไป)
  • จัดการข่าวสาร ประชาสัมพันธ์ และอัปโหลดภาพกิจกรรม
  • จัดการตารางกิจกรรมโรงเรียน และกิจกรรมเด่น (Next-Up)
  • แก้ไขวันเริ่มต้นนับเวลาปฏิบัติหน้าที่ (Uptime) และเปลี่ยนรหัสผ่านของตนเอง
  • ไม่มีสิทธิ์ ปรับเปลี่ยนระบบฐานข้อมูล (หน้าต่างถูกล็อก)
  • ไม่มีสิทธิ์ เข้าถึงหน้านี้ หรือจัดการบัญชีแอดมินคนอื่น
