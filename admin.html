ตั้งค่าระบบ & เวลาปฏิบัติหน้าที่ (System Settings)

ปรับแต่งวันเริ่มต้นนับเวลาปฏิบัติหน้าที่ (Duty Uptime) และรหัสความปลอดภัย

เชื่อมต่อฐานข้อมูล & เซิร์ฟเวอร์หลังบ้าน (MySQL + Cloudflare Tunnel)

กำลังตรวจสอบ...

ระบบนี้ช่วยให้รูปภาพและกิจกรรมถูกบันทึกลงฮาร์ดดิสก์และ MySQL ถาวร (แก้ปัญหาเบราว์เซอร์พื้นที่เต็ม 100%) และส่งผ่าน Cloudflare Tunnel ให้ทุกคนบนมือถือและคอมพิวเตอร์เครื่องอื่นมองเห็นได้

🌐 วิธีใช้งาน Cloudflare Tunnel:
1. ดับเบิลคลิกไฟล์ start-server.bat ในโฟลเดอร์ sarawat-backend เพื่อเปิด API
2. ดับเบิลคลิกไฟล์ start-cloudflare.bat จะได้รับลิงก์ เช่น https://xxxx.trycloudflare.com
3. นำลิงก์ HTTPS นั้นมาวางในช่องด้านบนแล้วกด "บันทึก URL" หรือนำไปใส่ใน js/api-config.js เพื่อให้คนอื่นในมือถือเห็นทันที!

กำหนดวันเริ่มต้นปฏิบัติหน้าที่ (Uptime Start)

ตัวเลขนับเวลาสดบนหน้าแรก (เดือน, วัน, ชั่วโมง, นาที, วินาที) จะคำนวณจากวัน-เวลาที่กำหนดนี้

เปลี่ยนรหัส PIN ผู้ดูแลระบบ (Admin PIN)

ใช้สำหรับเข้าใช้งานหน้า Admin Portal (admin.html) เพื่อความปลอดภัยของข้อมูล

สำรองและนำเข้าข้อมูล (Data Backup & Synchronization)

เนื่องจากเว็บดีพลอยบน Vercel แบบ Static Web ข้อมูลจะถูกบันทึกในเบราว์เซอร์ คุณสามารถสำรองข้อมูลเป็นไฟล์ JSON เพื่อนำไปเปิดในเครื่องอื่น หรือเก็บไว้เป็นชุดข้อมูลสำรองได้ตลอดเวลา

ส่งออกข้อมูลสำรอง (Export JSON)

ดาวน์โหลดข้อมูลข่าวสาร กิจกรรม ตารางงาน และการตั้งค่าทั้งหมดลงในไฟล์ sarawat_data_backup.json

นำเข้าข้อมูลสำรอง (Import JSON)

เลือกไฟล์ JSON ที่เคยสำรองไว้เพื่อกู้คืนข้อมูลหรืออัปเดตข้อมูลชุดใหม่

รีเซ็ตเป็นค่าเริ่มต้นจากโรงเรียน

หากต้องการล้างข้อมูลที่แก้ไขทั้งหมด และโหลดข้อมูลมาตรฐานตั้งต้นของสารวัตรนักเรียนปี 2569 กลับมา
